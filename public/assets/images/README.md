# Carpeta de Imágenes (`public/assets/images/`)

Aquí debes colocar las fotografías principales de la página web.

## Archivos recomendados:

1. **`hero.jpg`**
   - Fotografía principal para la portada (Hero).
   - Recomendación: Formato vertical o retrato (3:4 o 4:5), buena iluminación, de ustedes dos o de ella sonriendo.

2. **`gallery/`**
   - Carpeta para las fotografías del álbum scrapbook (`photo1.jpg`, `photo2.jpg`, etc.).
   - Puedes usar fotos verticales, horizontales y cuadradas.

3. **Formatos soportados:**
   - `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.

> **Nota:** Puedes subir o cambiar imágenes directamente desde el panel `/admin` sin necesidad de mover archivos manualmente si lo prefieres.
