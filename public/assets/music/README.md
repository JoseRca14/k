# Carpeta de Música (`public/assets/music/Virlán García - MMXX's [Official Video] - ShowBusiness`)



Aquí debes colocar la música de fondo para la experiencia web.

## Archivo recomendado:

- **`Virlán García - MMXX's [Official Video] - ShowBusiness`**
  - La canción que sonará suavemente de fondo una vez que ella presione **"Entrar →"**.
  - Formato recomendado: `.mp3` o `.m4a` a 128kbps o 192kbps para que cargue rápido.

> **Respaldo Inteligente:** Si no colocas ningún archivo MP3, la aplicación cuenta con un sintetizador ambiental que reproduce suaves acordes acústicos en tonos pastel mediante Web Audio API, por lo que nunca habrá silencio incómodo ni errores de reproducción.
