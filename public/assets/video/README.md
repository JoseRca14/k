# Carpeta de Videos (`public/assets/video/`)

Aquí debes colocar el video personal para la sección cinematográfica:
*"un momento que quiero guardar."*

## Archivo recomendado:

- **`memory.mp4`** (o `.webm`)
  - Un clip de video corto (de un viaje, un atardecer, una risa espontánea o un momento divertido juntos).
  - Formato recomendado: H.264 MP4 para compatibilidad universal con iPhone, Android y computadoras.
