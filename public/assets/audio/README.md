# Carpeta de Notas de Voz (`public/assets/audio/`)

Aquí debes colocar la nota de voz íntima para la sección:
*"escucha esto cuando estés sola."*

## Archivo recomendado:

- **`message.mp3`** (o `.m4a` / `.wav`)
  - Una nota de voz grabada desde tu celular diciéndole cosas lindas, felicitándola o recordándole cuánto la quieres.
  - La aplicación incluye un reproductor con forma de onda visual (waveform) moderna.
